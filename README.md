# 🌗 Theme Toggle

---

## 📖 Overview

This project provides a simple and intuitive theme toggle feature, allowing users to switch between light and dark modes seamlessly.

---

## 🚀 Features

- 🌞 Light mode and 🌙 Dark mode support.
- ⚡ Smooth transitions between themes.
- 🛠️ Easy to integrate into any project.

---

## 🛠️ Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/henrymishael/ThemeToggle.git
   ```
2. Navigate to the project directory:
   ```bash
   cd ThemeToggle

   ```

---

## 📋 Usage

1. Import the theme toggle component into your project.
2. Add the toggle button to your UI.
3. Enjoy seamless theme switching!
